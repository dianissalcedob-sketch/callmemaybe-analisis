# callmemaybe-analisis
CallMeMaybe es un servicio de telefonía virtual que necesita identificar a los operadores menos eficaces para mejorar la calidad del servicio y optimizar la atención al cliente.

El objetivo de este proyecto es analizar métricas operativas clave para detectar operadores con bajo desempeño, considerando:

Llamadas entrantes perdidas

Tiempos de espera elevados

Baja cantidad de llamadas atendidas

A partir del análisis exploratorio y métricas definidas, se identifican patrones de ineficiencia que pueden ser utilizados por supervisores para la toma de decisiones.
